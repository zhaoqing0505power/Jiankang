# 健康日记 · Jiankang

原生 Android 健康记录应用。按照已确认的十屏原型实现：首页、今日记录、身体数据、早餐、午餐、睡眠、运动、数据统计、营养建议、我的，并包含晚餐及设置子页面。

- 每日身高、体重、血压记录；BMI（体重指数）即时计算。
- 三餐食物选择、份量、粗略热量和常用食物收藏。
- 入睡/醒来时间选择，自动处理跨日睡眠，8 小时目标。
- 运动类型、分钟、消耗热量（可按体重估算）。
- 体重、血压、睡眠和运动趋势；地中海饮食习惯提示。
- 数据只存手机本地 SQLite，支持 JSON 备份导入与 CSV 导出，无需账号和联网。

重要：食物能量、运动消耗和饮食评分均为个人习惯记录用的估算值，不用于医学诊断。首次安装数据库为空，不包含演示数据。

## 构建

使用 Android Studio 打开此仓库（JDK 17，Android SDK API 36）。支持 Gradle 8.13、Android Gradle Plugin 8.11.1、Kotlin 2.2.20。执行 gradle :app:assembleDebug，产物位于 app/build/outputs/apk/debug/app-debug.apk。

GitHub Actions 中的 Android workflow 会自动编译、运行单元测试，并将可下载的 APK 上传为构建产物。工程初版不接入健康服务：个人健康数据未被静默读取或上传。

## v1.1 更新（2026-10-26）

- 早餐增加家常早餐分组：小米粥、牛奶、鸡蛋灌饼、小笼包、馅饼；食物热量按常见做法估算。
- 今日未填写身高时，从该日以前最近一次有效身高预填，保存时可修改。
- 运动下方新增“感悟”，包含可选心情标签和私人日记；数据库从 v1 无损升级到 v2。
- 首页新增经核对出处的每日古典名言、离线疾病预防与就医知识（含官方来源）及亮屏时间卡片。
- 手机使用管理默认为每日 300 分钟，自由设置 30—1440 分钟；Android 9+ 获得使用情况访问权限后按屏幕交互事件估算，提醒为自愿开启的 80%/100% 阈值通知，约半小时检查一次。
- 普通第三方 APP 不会强制锁机、不能自动限制其他 APP。系统级娱乐应用限制需用户在手机“数字健康/应用计时器/专注模式”中自行配置，紧急和必要功能不受本应用限制。
- JSON/CSV 备份增加感悟字段，兼容旧版 v1 JSON 备份；新设备导入备份后阈值提醒默认关闭，需再次核实权限。

### 安装升级与旧数据保护

本仓库 GitHub Actions 生成的是 **调试版 APK**，其调试签名密钥在不同 CI 运行之间可能改变。如果旧版已安装，**不要直接卸载旧版**：请先在旧版“我的 → 数据备份与导出 → 导出完整备份（JSON）”保存备份文件；尝试安装新版，若因签名不匹配失败，再卸载旧版、安装新 APK、通过“从 JSON 备份恢复”导入。**卸载会删除本地数据**，请先确认 JSON 文件可用并保管好包含个人健康信息的备份。

实际长期持续升级推荐采用私有且稳定的发布签名密钥；本仓库未包含私钥，也未将密钥公开到 GitHub。


## v1.2.0 变更

- 鸡蛋支持按“个”或“克”计算：1个按约50g可食部分估算；调整食物数量/重量时热量同步改变，可手动修正；保留旧记录。
- 工作日久坐振动：默认关闭，08:00—17:00（提醒09:00—16:00），每小时一次；可自定义时段，支持测试振动。系统省电/免打扰可能延迟或抑制。
- 首页移除每日名言、今日健康知识卡片；疾病预防资料仍可在“我的”中查阅。
- 固定 APK 签名：使用 Github Actions Secrets 提供私钥，并校对证书 SHA256。已安装旧临时 Debug 签名版本仍需先 JSON 备份再迁移。详见 docs/SIGNING.md。
