# 健康日记实现说明

## 页面与入口

1. 首页：圆形进度、体征、饮食完成度、睡眠和运动。
2. 今日记录：身体数据、早餐、午餐、晚餐、睡眠、运动六个入口。
3. 身体数据：身高、体重、收缩压/舒张压、体重指数（BMI）。
4. 早餐：食物搜索、推荐/常用、份量、热量、收藏、编辑和保存。
5. 午餐：相同记录方式、不同推荐食物。
6. 睡眠：时间选择、跨午夜计算、8小时目标。
7. 运动：运动类别、分钟、消耗千卡和按体重估算。
8. 数据统计：周/月/年体重、血压、睡眠、运动趋势，不补造缺失值。
9. 营养建议：地中海饮食多吃/少吃清单、当日习惯分数。
10. 我的：健康目标、常用食物、运动类型、提醒、备份与导出、关于。

## 数据与安全

- days：日期为主键，体征、睡眠、运动分别保存，保留其他记录。
- meals：每餐多种食物，保存名称、份量、热量、食物组与图标。
- SharedPreferences：收藏、8小时睡眠目标、150分钟每周运动目标和提醒设置。
- 睡眠记录归属于醒来当天，入睡时间晚于醒来时间时按跨日处理。
- 无网络权限、无登录与广告SDK、无云端上传；新设备数据库初始为空。
- JSON备份支持全量导入，CSV支持Excel查看。健康备份文件需妥善保管。
- 安卓通知提醒可能受省电策略影响，不能保证精确到分钟。
- 热量、运动消耗和地中海饮食评分均是简化估算，仅用于日常记录。

## 构建

Android Studio + Java 17，Gradle 8.13，Android SDK API 36。

- Windows：gradlew.bat :app:assembleDebug
- Linux/macOS：sh gradlew :app:assembleDebug
- 单元测试：gradle :app:testDebugUnitTest
- GitHub Actions：Android build and tests，成功后生成 Jiankang-debug-apk 下载产物。

## 回归测试要点

1. 新安装不显示假健康数据。
2. 切换日期录入不同体重，不互相覆盖。
3. 睡眠23:00→07:00为480分钟，23:40→00:10为30分钟。
4. 身体数据保存不改变三餐，早餐编辑不改变午餐。
5. 调整食物克数和千卡、收藏、重新打开后仍保留。
6. 周/月/年无记录日期保留空白。
7. JSON导出再导入可以恢复记录，CSV可以在Excel查看。
8. 设置通知后重新启动设备，提醒恢复。
